## ⚡ INSTALLATION GUIDE

```bash
# 1️⃣ Clone Repository
git clone https://github.com/Arslan-MD/Mishu-MD.git

# 2️⃣ Enter Directory
cd Mishu-MD

# 3️⃣ Install Dependencies
npm install

# 4️⃣ Setup Session
# Add your session credentials in settings.js

# 5️⃣ Start Bot
npm start

# 🎉 Bot is ready!
```
